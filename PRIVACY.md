# Privacy

PPTX Viewer processes PowerPoint files (`.pptx`, `.ppsx`, `.pptm`, `.ppsm`, `.potx`, `.potm`) locally inside your editor (VS Code, Cursor, Windsurf, etc.).

## Data collection

- No telemetry is collected by this extension.
- No personal data is intentionally collected by this extension.

## Local usage statistics

- The extension keeps aggregate counters on your machine only (number of decks/slides opened and rendering-warning counts by rule id) to help you report issues.
- These counters never include file contents, file names, file paths, or rendered images.
- They are never transmitted automatically. They appear only inside the prefilled text of a GitHub issue report that you explicitly open, where you can review and edit everything before submitting.

## Network access

- The extension does not send your file contents to external servers.
- The extension does not require network access for normal operation.

## Logs

- If an error occurs, the editor may show logs in `Output` and/or Developer Tools.
  These logs can include filenames and error details.
